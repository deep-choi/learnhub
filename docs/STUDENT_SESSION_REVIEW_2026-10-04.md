# 학생 관점 학습 체험 — 2026-10-04

## 환경과 범위

- 실제 Chrome 로그인 세션에서 `http://localhost:3002/`를 UI로 조작했다. AI 응답을 대역으로 교체하지 않았다.
- 초보 학습자 역할로 조건부확률을 요청하고 의도적으로 오답을 제출했다. 이는 제품 체험이며 실제 사람의 학습 효과 검증은 아니다.
- 새 과목: **주사위와 카드로 깨치는 조건부확률 원리 탐구**. 3단계, 6개 레슨 중 **새로운 정보와 표본공간 축소**를 완료했다.
- 체험 중 생성한 대화, 과목, 자료, 교정 메모, 결과는 계정에 남겼다. 기존 학습 내용은 편집하지 않았다. 모델 설정은 최초의 GPT-5.6 Luna / 높음으로 복원했다.
- 최초 체험 당시 제품 코드는 수정하지 않았다. 아래 관찰 이후 반영한 수정과 검증은 마지막 절에 별도로 기록한다.

## 수행한 학습

1. 분수와 백분율은 알지만 조건부확률은 모른다고 입력했다.
2. 주사위 짝수 조건에서 2의 확률을 `1/6`이라고 답했다. 튜터가 `{2,4,6}`으로 후보를 줄여 설명했고, 더 쉬운 확인 문제에 답했다.
3. 직접 작성한 조건부확률 TXT 자료를 첨부했다. 카드 예시의 분모를 질문하고 결과 창의 원문 인용을 펼쳐 확인했다.
4. 자료 기반 퀴즈를 생성하고 5문제 중 4문제 정답, 1문제 의도적 오답을 제출했다. 오답 해설은 정확했다.
5. 과목 첫 레슨을 진행하며 메모에 `따라서 2일 확률은 1/6이다.`를 저장했다. 메모를 참고 자료로 선택해 교정을 요청하고 `1/3` 교정안을 반영했다.
6. 교정 메모로 암기 카드를 생성해 앞뒤 전환 및 다음 카드 이동을 사용했다.
7. 그래프 뷰를 열어 현재 개념과 연결된 11개 개념의 지도를 확인했다.
8. 레슨의 4단계를 읽고, 새 문제인 '3 이상의 눈'의 경우 수에 `4개`를 제출했다. 정답으로 레슨 완료가 표시됐다.
9. 학습 기록에서 해당 개념의 `맞힘 1 / 틀림 0`과 다음 미완료 레슨 제안을 확인했다.
10. 레슨에 재진입해 교정된 메모가 `1/3`으로 보존된 것을 확인했다. 설명 그림도 생성했다.
11. 자료 퀴즈를 다시 열어 풀이 상태가 초기화되는 것을 확인했다.

## 우선 개선 사항

### P1: 학습 진입 중 실제 오류

- 최초 GPT-5.6 Luna / 높음 응답에 `AI 응답을 확인할 수 없어 다시 시도해 주세요.`가 나왔다.
- 서버는 tutor-chat 응답의 schema_validation 오류로 502를 반환했다. 모델 연결 자체가 안 되는 오류라고 단정할 수 없다.
- Gemini 3.8 Flash / 높음으로 대화와 진단은 진행됐지만, 과목 생성은 재시도까지 두 번 실패했다.
- analyze-subject 로그에서 `maxOutputTokens:2600`, `finishReason:MAX_TOKENS`, JSON 파싱 실패를 확인했다. thinkingTokenCount는 각각 1390, 2493이었다.
- 추론 단계를 낮음으로 바꾸고 재시도하자 생성됐다. 일반 학생이 설정을 바꿔야만 학습에 진입하는 상황을 없애야 한다.

### P1: 자료 퀴즈의 풀이가 학습 기록과 연결되지 않음

- 자료 퀴즈 완료 화면에는 `4 / 5 정답`이 표시됐다.
- 학습 기록 → 오답 기록은 `기록된 문제 0개`, `저장된 오답이 없습니다.`였다.
- 같은 퀴즈 결과를 다시 열면 선택 답과 점수가 사라지고 미응답 상태로 열린다.
- UI에는 '퀴즈에서 틀린 문제는 이 화면에 자동으로 정리됩니다.'라고 적혀 있어 실제 동작과 기대가 어긋난다.
- 풀이 이력 저장, 오답 기록, 다시 풀기, 후속 학습 추천을 연결할 필요가 있다.

### P1: 교정한 메모와 열린 편집기가 서로 다른 내용을 표시

- '메모에 반영' 후 자료함에는 `1/3`, 옆 메모 편집기의 실제 입력 값에는 `1/6`이 남았다.
- 화면을 나갔다가 다시 들어오면 편집기도 `1/3`으로 갱신됐다. 저장된 데이터 자체는 교정됐지만 열린 편집기가 갱신되지 않는다.
- 오래된 편집 내용을 다시 저장할 위험이 있다. 이번 체험에서는 덮어쓰기를 실행하지 않았다.

### P2: 설명 그림이 시각적 설명을 제공하지 못함

- 요청: '주사위 전체 6개 중 짝수 3개만 남는 과정을 그림으로 보여줘.'
- 결과는 초기 표본공간 / 새로운 조건 / 축소 / 계산 기준의 글 중심 단계 카드였다. 주사위나 후보가 제외되는 도형 표현은 없었다.
- 답변에 '제공된 sources 자료가 없으므로 ... 시각화용 슬라이드'라는 내부 용어도 노출됐다.
- 현재 결과는 단계 요약에 가깝다. 기능명과 맞게 후보 집합, 제외 항목, 남은 항목을 그림으로 표현할 필요가 있다.

### P2: 짧은 학습 요청과 안내 문구

- 퀴즈 '3개' 요청에 5개를 생성했다.
- 시작 진단마다 '알고 있는 만큼 편하게 ... 설명의 깊이와 배울 시작점 ...' 문장이 반복됐다. 흥미 사례를 고르는 질문에도 같은 문구가 붙었다.
- 레슨의 '직접 확인' 단계에서 질문과 정답을 동시에 보여줬다. 학생이 먼저 풀 수 있는 단계와 풀이 예시를 구분하면 좋다.
- 학습 기록에는 내부 산정 방식 설명이 많고, 문제 하나를 맞힌 새 개념에 '내 실력 80%'와 '참고 지표 높음'이 표시됐다. 제한을 설명하는 긴 문구보다 관찰 사실인 '확인 문제 1개 정답'을 중심으로 보여주는 편이 이해하기 쉽다.

## 잘 작동한 부분

- 오개념을 구체적으로 바로잡고 쉬운 확인 문제로 내려오는 튜터 반응.
- 첨부 자료에서 실제 문장을 인용하고 원문을 펼쳐 확인하는 흐름.
- 메모를 골라 참고시키고 교정안을 직접 반영하는 기능.
- 교정된 메모 기반 암기 카드와 카드 전환.
- 정규 레슨의 확인 문제 → 완료 → 개념 기록 → 다음 레슨 연결.
- 입력창의 세 도구 버튼은 기능 수에 비해 기본 화면을 간결하게 유지한다.

## 이번 체험에서 확인하지 않은 것

- 실제 사람의 마이크 발화, PDF/Office/이미지/음성 업로드, 웹 자료 검색, 슬라이드/영상, 다른 기기 동기화와 운영 배포.
- 첨부 파일은 TXT였다. 이전 테스트 결과를 이번 실사용 결과로 대체하지 않는다.
- 설명 그림 PNG 저장 버튼을 눌렀지만 브라우저 도구의 다운로드 대기가 시간 초과됐다. 다운로드 성공/실패는 이번 체험으로 확정하지 않는다.

## 후속 수정 및 검증

- 비어 있는 튜터 선택 필드를 정규화했다. 과목 생성 출력 예산을 늘리고 구조화 응답 엔드포인트의 추론 예산을 제한했다. GPT 튜터 / Gemini 과목 생성은 높은 추론 설정 요청으로 실제 API 200을 확인했다.
- 자료 퀴즈의 답·점수를 저장하고 오답 기록에서 원래 퀴즈를 다시 열 수 있게 했다. 다시 맞힌 오답은 해결 처리한다. 과목에서 만든 퀴즈는 해당 개념의 문제 수에 반영하며 레슨 완료를 임의로 부여하지 않는다.
- 메모 교정·되돌리기는 열린 편집기에 즉시 반영한다. 편집 중 충돌은 초안을 보존하고 사용자가 최신 메모를 불러오도록 했다.
- 설명 그림은 후보 원소, 제외 표시, 남은 원소, 화살표를 SVG로 표현한다. 과거에 저장한 슬라이드형 결과도 계속 열 수 있다.
- 요청한 퀴즈 개수를 스키마와 결과 검증에 반영했다. 실제 API에서 3문항 생성과 새 다이어그램 구조를 확인했다.
- 진단 반복 안내를 줄이고, 레슨 진행 요청은 현재 단계 동작으로 연결했다. 확인 문제 전의 튜터 문맥에 미래 풀이 단계를 전달하지 않는다. 학습 기록은 추정 퍼센트 대신 실제 풀이·완료 수를 표시한다.
- 변경 관련 단위 테스트 44개, 브라우저 테스트 4개 통과. 브라우저 테스트는 대역 AI로 첨부·교정·오답 재진입·풀이 복원·PNG 저장·음성 상태를 검증했다. 실제 마이크 발화와 다른 기기 동기화 검증을 대체하지 않는다.
- 실제 로그인 Chrome에서도 새 퀴즈가 요청대로 3개 생성됐다. 첫 문제에 6을 제출해 오답 1개를 만들고, 오답 기록에서 원래 퀴즈를 열어 나머지 문제를 풀었다. 다시 풀기 후 첫 문제에 3을 답하자 해결 1개 / 다시 볼 문제 0개로 바뀌었다. 증거: `test-results/student-session/fixed-mistakes.jpg`.
- 최종 타입 검사와 웹·Functions 빌드 통과. 전체 단위 테스트는 244개 중 233개 통과 / 기존 초기 설정 계약·대화 복원 테스트 11개 실패로, 전체 테스트 통과 상태는 아니다.
- 운영 배포는 수행하지 않았다.
