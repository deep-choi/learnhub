# 채팅 학습 도구

자유 채팅과 레슨 채팅의 입력창에서 같은 도구를 사용한다. 기본 화면에는 자료·메모, 학습 도구, 음성 버튼만 표시한다. 선택한 자료와 작업은 제거 가능한 칩으로 표시한다.

## 지원 기능

- 자료함: TXT, Markdown, CSV, PDF, DOCX, PPTX, PNG/JPEG/WebP, MP3/WAV/M4A/OGG/WebM. 파일당 4MB, 텍스트 12만 자, PDF 200쪽 제한.
- PDF·Office 문서는 브라우저에서 텍스트를 추출한다. 텍스트 없는 PDF, 이미지, 녹음은 서버의 Gemini로 추출·전사한다. 원본 바이너리가 아니라 추출된 내용과 페이지/슬라이드 표시를 저장한다. DOCX/PPTX 안의 그림은 OCR 대상이 아니다.
- 자료는 공통 또는 과목별로 분류한다. 대화에 최대 8개를 명시적으로 연결한다. 긴 자료는 질문과 최근 대화에 관련된 부분을 발췌하며, 문서 전체가 매 요청에 들어가지는 않는다.
- 내 메모는 현재 내용을 읽어 참고한다. 교정안은 원문·수정안·이유로 표시하며, 사용자 선택으로만 반영한다. 원문 변경/중복 시 적용을 거절하고, 이후 편집이 없으면 되돌릴 수 있다.
- 핵심 정리, 쉬운 설명, 암기 카드, 객관식 퀴즈, 설명 그림, 슬라이드, 자막 설명 영상을 생성한다. PNG, HTML 슬라이드, WebM 자막 영상, Markdown으로 내려받는다. 영상은 자막 슬라이드 형식이며 음성 진행자나 팟캐스트를 생성하지 않는다.
- 인용문이 실제로 선택된 자료에 있는지 서버와 브라우저에서 검증한다. 결과의 ‘자료·결과 보기’에서 인용문과 자료 본문을 확인한다.
- 웹 검색은 Gemini Google Search grounding을 사용하고 실제 grounding 출처와 검색 제안을 표시한다. 개별 검색 결과를 선택하면 원문을 가져온다. AI 조사 요약 저장은 원문 저장과 구분한다.
- 링크 가져오기는 공개 HTTPS HTML·텍스트·PDF만 지원한다. 로그인 필요 페이지, 동적 페이지, 유튜브 자막 수집은 지원하지 않는다. DNS/IP 검증, 주소 고정, 리다이렉트 재검증으로 내부 주소 접근을 차단한다.
- 음성은 같은 대화 기록과 연결 자료를 사용한다. Web Speech 지원 브라우저는 발화 종료 후 자동 전송하고 음성 답변 뒤 다시 듣는다. 미지원 브라우저는 MediaRecorder와 Gemini 전사를 사용하며 ‘보내기’ 또는 30초 제한으로 발화를 마친다. 답변 중 ‘말하기’로 끼어들 수 있다. 화면 이탈·종료 시 마이크와 음성을 정리한다.

## 저장과 서버

`ai_learnhub_study_library_v1`은 기존 학습 백업·계정 동기화·로그아웃 삭제에 포함된다. 자료 60개, 결과 40개, 합계 90만 자를 초과하면 저장을 거절한다. 결과 저장 실패 시 다운로드 가능한 결과를 현재 화면에 남긴다. 기존 데이터 스키마 버전은 유지하며 선택 필드를 추가했다.

`/api/ai/study`, `/study-import`, `/study-research`, `/study-url`은 기존 인증 경로를 사용한다. AI 호출은 기존 admission/계정별 사용량 예약을 거친다. 일반 학습 생성은 선택 모델을 사용하고, 미디어 인식과 검색은 Gemini 설정이 필요하다. 원문 링크 가져오기는 AI 호출을 사용하지 않는다.

서버와 Firebase Hosting의 Permissions-Policy는 `microphone=(self)`이다. 마이크는 HTTPS 또는 localhost에서 브라우저 권한이 필요하다.

## 검증

```powershell
npm run lint
npm test
npx playwright test
npm run build
npm run build:functions
```

브라우저 테스트는 별도 3013 포트에서 개발 전용 fixture를 실행한다. Chrome 경로는 `CHROME_PATH`로 변경할 수 있다. 테스트의 AI 응답과 음성 API는 재현 가능한 대역을 사용하며 실제 사용자 계정에 쓰지 않는다.

실제 AI 검증은 로컬 개발 서버를 켠 뒤 `STUDY_BASE_URL`(기본 `http://localhost:3012`)을 지정하고 `node scripts/check-study-live.mjs`로 실행한다. 실제 API 사용량이 발생한다. 미디어 검증 스크립트는 `test-results/study-voice.wav` 한국어 음성 fixture가 필요하다.
