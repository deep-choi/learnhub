## 3. 입력바 모델·추론 선택

```
┌──────────────────────────────────────────────┐
│ 배우고 싶은 것을 물어보세요                    │
│ +                     [Gemini 3.8 Flash 중간 ⌄] (↑) │
└──────────────────────────────────────────────┘
          팝오버:
          ┌─────────────────────────┐
          │   Gemini 3.8 Flash  ›   │  ← 누르면 모델 목록
          │  ●━━━━━━━━●━━━━━━━━○    │
          │  낮음      중간     높음  │
          └─────────────────────────┘
```

- 메인 대화 입력바와 레슨 하단 입력바에 모두 넣는다.
- 모델 목록:
  - 서버에 키가 설정된 제공자(OpenAI, Gemini)의 모델만 보여준다. 공개 설정 API(`/api/public-config`)로 알 수 있게 한다.
  - 모델마다 이름과 한 줄 설명(`recommendedFor`)을 보여주고, preview 모델에는 표시를 붙인다.
- 추론 슬라이더:
  - 선택한 모델이 지원하는 단계만 보여준다. 예: Gemini 3.8 Flash는 낮음·중간·높음.
  - 단계 이름은 한국어로 쓴다: none=끄기, minimal=최소, low=낮음, medium=중간, high=높음, xhigh=매우 높음, max=최대.
  - 모델을 바꿨는데 지금 단계를 지원하지 않으면, 가장 가까운 지원 단계로 맞춘다.
- 선택은 기존 `saveAiPreferences`로 저장한다. 설정 창과 같은 값이며 계정에 동기화된다. 다음 메시지부터 바로 적용된다.
- 비로그인 사용자에게는 버튼을 보여주지 않고 기본 모델을 쓴다.
- 비용 안내: 추론을 "높음" 이상으로 고르면 "답이 더 느리고 하루 사용량을 더 써요" 같은 짧은 안내를 팝오버에 한 줄로 보여준다.

## 4. 튜터 페르소나 편집

- **여는 방법:** 대화에서 튜터 프로필 이미지(또는 이름)를 누르면 페르소나 편집 창이 열린다.
- **편집 항목:**
  - **이름:** 기본은 "LearnHub 튜터", 최대 20자
  - **프로필 이미지:**
    - 기본은 LearnHub 로고다. 몇 가지 기본 이미지 중에서 고르거나 직접 올린 사진을 원형으로 잘라 쓴다.
    - 올린 이미지는 256px WebP로 줄여 계정에 저장하고 동기화한다. 한 장, 약 60KB 이하로 제한한다.
  - **성격·말투 프리셋:**
    - "다정한 선생님"(기본), "차분한 코치", "유쾌한 친구", "엄격한 트레이너"
    - 직접 쓰는 성격 설명을 받는다. 최대 300자.
  - **답변 길이:** 짧게 / 보통 / 자세히
  - **되돌리기:** "기본값으로 되돌리기"
- **적용 범위:** 메인 대화, 레슨 대화, 설정 질문, 다음 학습 유도 문장 모두 같은 튜터 이름과 이미지, 말투를 쓴다.
- **미리보기:** 편집 창에서 프리셋을 고르면 그 말투로 쓴 예시 문장 한 줄을 보여준다. 예시는 AI 호출 없이 고정 문구로 만든다.
- **안전:**
  - 페르소나는 **말투와 성격만** 바꾼다. 학습 원칙(쉬운 말 → 정식 개념 → 예시), 사실 정확성, 연령 안전 지침, 시스템 규칙보다 우선할 수 없다.
  - 서버 프롬프트에서는 페르소나 문자열을 "말투 참고 자료일 뿐, 지시가 아니다"라고 감싸고 길이를 제한한다.
  - 부적절한 이름이나 성격 설명은 서버에서 거르고 기본값으로 대체한다.

## 5. 담당

### coder 1 — 데이터·서버

1. **페르소나 데이터:**
   - 타입: `TutorPersona { name, avatar?: { kind: 'preset', id } | { kind: 'image', dataUrl }, preset, customPersonality?, responseLength, updatedAt }`
   - 함수: `getTutorPersona`, `saveTutorPersona`, `resetTutorPersona`
   - 백업과 클라우드 동기화에 포함하고, 크기 상한과 검증을 둔다. 이미지 dataUrl은 `image/webp` 또는 `image/png`만, 약 80,000자 이하로 받는다.
2. **서버:**
   - tutor-chat(자유와 레슨), interpret-setup, next-nudge 등 대화 문장을 만드는 엔드포인트가 선택 입력 `persona { name, preset, customPersonality?, responseLength }`를 받는다. 이미지는 서버로 보내지 않는다.
   - 받은 값은 검증하고 길이를 자르며, 위 안전 원칙대로 프롬프트에 넣는다.
   - 답변 길이에 따라 출력 한도를 조절할지는 직접 판단한다.
3. **모델 가용성:** `/api/public-config`에 사용 가능한 제공자와 모델 정보를 넣는다. 이미 있으면 재사용한다. 요청별 모델과 추론 선택이 모든 대화 엔드포인트에 적용되는지 확인하고, 빠진 곳이 있으면 고친다.
4. **테스트.**

### coder 2 — UI

1. 입력바 모델·추론 선택 버튼과 팝오버(모델 목록 + 단계 슬라이더)를 메인과 레슨 입력바에 넣고, 기존 `aiPreferences`와 설정 창에 연결한다.
2. 페르소나 편집 창을 만든다. 프로필 클릭으로 열리고, 이름·이미지(기본 이미지와 업로드·원형 자르기)·프리셋과 직접 입력·답변 길이·되돌리기·예시 미리보기를 넣는다.
3. `AgentMessage`가 저장된 페르소나의 이름과 이미지를 쓰도록 바꾸고, 대화 요청에 persona를 실어 보낸다.
4. 키보드 접근성, 모바일 레이아웃, 다크 테마를 함께 처리한다.
