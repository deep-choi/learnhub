# 대화 중심 미니멀 화면 개편 계획 (2026-10-02)

작성: UX/PM 탭. 구현은 coder 1(데이터·서버), coder 2(UI)가 나눠서 진행한다. 이전 계획 `docs/KNOWLEDGE_GRAPH_PLAN_2026-10-01.md`의 기능(개념 그래프, 다음 학습 유도, 선택형 퀴즈)은 그대로 유지하고, 화면 구조만 단순하게 바꾼다.

## 1. 사용자 결정

- 목표: 사용자가 쉽고 간편하게, 들어오자마자 바로 몰입할 수 있는 화면
- **홈 화면을 없앤다.** AI 대화 화면이 첫 화면(메인)이 된다.
- 첫 화면은 **Gemini 시작 화면처럼** 단순하게 만든다.
  - 부드러운 파란 빛 번짐 배경
  - 가운데 인사 한 줄
  - 둥근 입력창 하나
- 사이드바는 **Codex 앱처럼 2단**으로 만든다.
  - 왼쪽: 아이콘 레일
  - 오른쪽: "새 대화" 버튼, 프로젝트 폴더와 그 안의 대화 목록, "최근" 목록

## 2. 화면 구조

### 첫 화면 (메인 = AI 대화 시작)

```
            (부드러운 파란 빛 번짐 배경)

           무엇을 배워볼까요?              ← 로그인: "OO님, 무엇을 배워볼까요?"

   ┌──────────────────────────────────────┐
   │ +   배우고 싶은 것을 물어보세요     ↑ │
   └──────────────────────────────────────┘
      지난번엔 '낚시 안전 수칙'까지 했어요 · 이어가기   ← 이어갈 학습이 있을 때만, 작은 한 줄
```

- 화면에는 인사, 입력창, (있을 때만) 이어가기 한 줄 외에 아무것도 두지 않는다. 예시 칩, 로드맵 카드, 샘플 레슨, "이렇게 배워요" 같은 설명 섹션은 없앤다.
- 입력창의 `+` 메뉴:
  - 과목으로 만들기
  - 문제 풀기
  - 준비된 과정 둘러보기 (기존 로드맵 30개 카탈로그는 여기로만 들어간다)
- 메시지를 보내면 같은 화면이 대화 화면으로 바뀐다. 인사와 배경은 사라지고, 입력창은 아래로 내려간다.
- **대화가 학습의 입구다.**
  - 사용자가 "낚시 배우고 싶어"처럼 배우고 싶다는 뜻을 보이면, AI가 답과 함께 대화 안에 **과목 미리보기 카드**(이미 만든 개념 지도 미리보기)를 띄운다.
  - "이 지도로 시작하기"를 누르면 과목이 만들어지고 첫 레슨으로 이어진다.
  - 별도의 과목 만들기 모달로 보내지 않는다.
- 레슨 화면(대화형)과 레슨 옆 미니 그래프, 다음 학습 유도, 선택형 퀴즈는 지금 그대로 유지한다.

### 사이드바 (2단)

```
┌────┬──────────────────────────┐
│ 💬 │ LearnHub            🔍   │
│ 🗺 │ ✎ 새 대화                │
│ 📈 │                          │
│    │ 과목                  +  │
│    │ 📁 원리로 배우는 낚시 입문 │
│    │    물가 안전과 보호 장구 ●│  ← 현재 레슨 강조
│    │    물고기의 감각과 입질   │
│    │ 📁 UI 디자인 기초         │
│    │                          │
│    │ 최근                      │
│    │  낚시 미끼 고르는 법 질문  │
│    │  분수 나눗셈 다시 설명     │
│    │                          │
│ ⚙  │                          │
│ 👤 │                          │
└────┴──────────────────────────┘
```

- **왼쪽 아이콘 레일**
  - 위: 대화(메인), 지도, 기록
  - 아래: 설정, 프로필(로그인/계정)
  - "홈", "과목" 아이콘은 없앤다. 복습 알림 배지는 "기록" 아이콘에 붙인다.
- **오른쪽 패널**
  - 맨 위: 서비스 이름, 검색 아이콘, "새 대화" 버튼
  - **과목** 섹션 (Codex의 "프로젝트"에 해당)
    - 과목마다 접고 펼 수 있는 폴더 하나
    - 펼치면 레슨 목록이 보이고, 현재 레슨과 완료한 레슨을 표시한다.
    - 폴더 옆 `…` 메뉴: 목차 보기, 문제로 실력 확인, 보관
  - **최근** 섹션: 레슨에 묶이지 않은 자유 대화 목록 (최신순, 제목은 첫 질문으로 자동 생성)
  - 패널은 접을 수 있다. 접으면 레일만 남는다.
- **모바일**: 레일과 패널을 함께 서랍(drawer)으로 열고 닫는다. 첫 화면은 입력창만 보인다.
- 색은 지금 테마 토큰을 따르고, 라이트와 다크를 모두 지원한다. 캡처의 어두운 색은 참고용이다.

### 없애거나 숨기는 화면

| 화면 | 처리 |
|---|---|
| 홈 (`HomeView`, `home/*`) | 삭제. 기본 화면을 AI 대화로 바꾼다. |
| 과목 카탈로그 (`CoursesView`) | 내비게이션에서 뺀다. `+` → "준비된 과정 둘러보기"로만 들어간다. |
| 과목 상세 (`CourseDetailView`) | 사이드바 폴더 `…` → "목차 보기"로만 들어간다. |
| 기록·지도·복습·오답 | 유지. 기록 화면 안에서 복습과 오답으로 들어간다. |
| 과목 만들기 모달 | 대화 안의 미리보기 카드로 대체한다. 모달은 `+` → "과목으로 만들기"에서만 쓰거나 같은 카드로 통일한다. |

### 비로그인 사용자

- 같은 첫 화면을 본다.
- 첫 메시지가 배우고 싶다는 뜻이면, 로그인 없이 과목 미리보기 카드(`/api/ai/preview-course`, IP 제한 있음)를 보여준다.
- 일반 대화를 이어가거나 "이 지도로 시작하기"를 누를 때 로그인을 요청한다. 로그인한 뒤에는 입력한 내용과 미리보기가 그대로 이어져야 한다.

## 3. coder 1 — 데이터·서버

**소유 파일:** `src/services/*`, `src/domain/*`, `src/types/*`, `server.ts`, `server/*`, 관련 `tests/*`

1. **자유 대화 저장소**를 만든다. 지금 AI 대화는 화면 상태에만 있어서 새로고침하면 사라진다.
   - 새 타입 `ChatSession { id, title, createdAt, updatedAt, messages[] }`
   - 함수: `listChatSessions()`, `getChatSession(id)`, `createChatSession(firstMessage)`, `appendChatMessage(id, message)`, `renameChatSession`, `deleteChatSession`
   - 제목은 첫 질문에서 자동으로 만든다 (AI 호출 없이 잘라내기, 최대 30자 정도).
   - 백업 허용 목록과 클라우드 동기화에 포함한다. 기존 snapshot과 하위 호환되어야 한다. 세션 수와 메시지 수에 상한을 둔다.
2. **대화에서 "배우고 싶다"를 감지**한다.
   - 자유 대화 응답(`/api/ai/tutor-chat`)에 선택 필드 `learningIntent: { subject: string } | null`을 추가한다.
   - 사용자가 새 주제를 체계적으로 배우고 싶어 할 때만 채운다.
   - 비로그인 첫 메시지용으로, 짧은 입력이 학습 의도인지 판별하는 가벼운 방법(규칙 또는 작은 AI 호출)을 `preview-course` 쪽에 둔다. 비용을 고려해 고른다.
3. **자유 대화가 학습자를 알게** 한다. 자유 대화 요청 시 서버에 개념 그래프 요약(현재 위치, 최근 배운 개념 몇 개, 다시 볼 개념)을 짧게 함께 보낸다. 형식과 상한은 직접 정한다.
4. **사이드바용 데이터**를 제공한다.
   - 과목별 레슨 목록과 상태(완료, 현재 위치)
   - 레슨 대화 기록 존재 여부
   - 이미 있는 함수로 충분하면 새로 만들지 않는다.
5. 테스트: 세션 저장·상한·동기화 하위 호환, `learningIntent` 스키마 검증

## 4. coder 2 — UI

**소유 파일:** `src/components/*`, `src/App.tsx`, `src/index.css`, `src/main.tsx`. 이 중 `server.ts`, `src/services/*`, `src/domain/*`, `src/types/*`는 수정하지 않는다.

1. **메인 대화 화면**을 만든다. `AiChatView`를 Gemini 스타일 시작 화면 겸 대화 화면으로 다시 만든다.
   - 기본 `activeView`를 이 화면으로 바꾼다.
   - 배경 빛 번짐은 CSS 그라디언트로만 만든다. 이미지를 쓰지 않는다.
   - 인사 문구는 로그인 여부에 따라 바꾼다.
2. **입력창**: `+` 메뉴(과목으로 만들기 / 문제 풀기 / 준비된 과정 둘러보기), 전송 버튼, Enter 전송, Shift+Enter 줄바꿈
3. **대화 안 과목 미리보기 카드**: `learningIntent`가 오거나 `+` → "과목으로 만들기"를 고르면 기존 `CoursePreviewPanel`(개념 지도 미리보기)을 대화 메시지 카드로 띄운다. "이 지도로 시작하기"를 누르면 과목을 만들고 첫 레슨으로 간다.
4. **이어가기 한 줄**: `getResumeContext()`가 있을 때만 입력창 아래에 작게 보여준다. 홈에 있던 큰 배너와 "이어서 학습" 카드는 없앤다.
5. **2단 사이드바**: 위 그림대로 `Sidebar.tsx`를 다시 만든다.
   - 레일: 대화·지도·기록 / 설정·프로필
   - 패널: 새 대화, 과목 폴더(레슨 목록), 최근 대화
   - 패널 접기, 모바일 서랍
   - 현재 화면이나 레슨 강조, 키보드 접근성
6. **홈과 정리 대상 화면**: `HomeView`와 `home/*`를 지우고, 위 표대로 진입점을 옮긴다.
   - `SampleLessonPreview`와 `homeSamples`가 다른 곳에서 안 쓰이면 함께 지운다.
   - 지운 화면을 가리키는 테스트는 새 구조에 맞게 고친다.
7. **비로그인 흐름**: 첫 화면에서 미리보기까지는 로그인 없이 되고, 그다음 행동에서 로그인하며, 로그인 후 내용이 이어지게 한다.
8. **시각 기준**: 여백을 넉넉하게 둔다. 첫 화면 요소는 3개 이하로 둔다. 장식 아이콘과 설명 문구는 최소로 한다. 대화 본문 폭은 약 760px로 둔다.

## 5. 공통 규칙

- coder 1이 먼저 `ChatSession` 타입과 함수 시그니처, `learningIntent` 타입을 컴파일되는 상태로 만든다. coder 2는 그 전까지 mock으로 화면을 만든다.
- 이전 작업과 Firebase 전환 변경이 커밋되지 않은 상태다. 되돌리거나 무관한 파일을 재포맷하지 않는다. 커밋·푸시는 하지 않는다.
- 자기 소유가 아닌 파일은 수정하지 않는다. 필요한 변경은 보고에 적는다.
- UI 문구는 한국어 존댓말이다. 전 연령, 모든 주제 기준으로 쓴다.
- 끝나면 `npm run lint`, `npm test` 결과와 함께 다음을 보고한다: 바꾼 파일, 계약에서 달라진 점, 남은 일. coder 2는 SendMessage로 learnhub-13에게도 보낸다.

## 6. 대화형 과목 설정 (2026-10-02 추가)

사용자 결정: 수준·목적·하루 학습 시간은 설정 화면이 아니라 **AI가 대화로 물어본다.** 질문을 통해 학습자의 수준을 파악하는 것을 좋은 경험으로 본다.

### 흐름

1. 사용자: "UI 디자인 배우고 싶어요" (학습 의도 감지)
2. AI가 짧게 답한 뒤 이어서 묻는다: "시작하기 전에 몇 가지만 여쭤볼게요."
   - **경험 (수준):** "UI 디자인을 해본 적 있으세요?" → `처음이에요` / `조금 해봤어요` / `꽤 해봤어요`
     - `조금 해봤어요`나 `꽤 해봤어요`를 고르면, 수준을 가늠할 **아주 짧은 확인 질문 1개**를 할 수 있다 (예: "버튼과 링크를 구분하는 기준을 한 줄로 말해 보시겠어요?"). 답을 채점하지 않고 수준 추정에만 쓴다. 이 단계는 생략할 수 있다.
   - **목적:** "어디에 쓰고 싶으세요?" → `취미·교양` / `일·과제` / `시험 준비` / `그냥 궁금해서`
   - **하루 시간:** "하루에 얼마나 공부할 수 있으세요?" → `10분` / `15분` / `30분`
3. 답이 모이면 그 설정으로 개념 지도 미리보기 카드를 띄운다. 카드에 "처음 · 취미 · 하루 15분"처럼 설정을 작게 보여주고, 누르면 고칠 수 있다.

### 원칙

- 질문은 **최대 3개(확인 질문 포함 4개)**, 한 번에 하나씩 묻는다.
- 매 질문에 빠른 답 칩을 주고, 자유 입력도 받는다. AI가 자유 답을 해석한다.
- 언제든 `바로 만들어 주세요` 칩으로 남은 질문을 건너뛴다. 건너뛴 항목은 기본값(초급 · 원리 탐구 · 15분)을 쓴다.
- 나이는 묻지 않는다. 수준은 경험과 확인 질문으로만 추정한다.
- 비로그인 사용자도 같은 질문을 거친 뒤 미리보기를 본다. 질문 단계는 AI 호출 없이 고정 문구로 진행해 비용과 미리보기 제한을 쓰지 않는다. 확인 질문은 로그인 사용자에게만 한다.
- 질문과 답은 대화 기록(ChatSession)에 그대로 남는다.

### 담당

- **coder 1:**
  - 타입 `CourseSetup { level?, goal?, dailyMinutes?, experience?, levelEvidence? }`과 질문 단계 정의(`SetupStep`)를 만든다.
  - 자유 답·확인 질문 답을 해석해 level/goal/dailyMinutes로 바꾸는 서버 엔드포인트나 tutor-chat 확장을 만든다.
  - `preview-course`와 과목 생성 요청이 이 설정을 받게 한다. 테스트를 포함한다.
- **coder 2:**
  - 대화 안의 질문 흐름 UI: 빠른 답 칩, 건너뛰기, 설정 요약 표시와 수정, 미리보기 카드 연결
  - 비로그인 흐름, 대화 기록 저장
