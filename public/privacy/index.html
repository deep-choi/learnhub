개인정보처리방침

제이엔메드는 LearnHub의 앱과 웹 서비스에서 다음 정보를 처리합니다.

처리하는 정보와 목적

로그인 정보(이메일, 계정 식별자, 이름·프로필 사진), 학습 과정과 진도, AI 대화, 노트·자료·첨부 이미지, 문제 풀이·오답·복습 기록, 음성 기능에서 입력한 음성·변환 텍스트, AI 사용량과 콘텐츠 신고. 로그인, 서비스 기능 제공, 계정 간 동기화, 사용량 관리, 오류 대응과 안전한 서비스 운영에 사용합니다. 기기에는 로그인 세션, 설정과 기능에 필요한 로컬 기록이 저장됩니다. 서버·호스팅 제공자는 접속 IP와 요청·오류 로그를 처리할 수 있습니다.

서비스 제공자와 공개 정보

Google Firebase Authentication, Firestore, Cloud Functions와 Hosting을 이용해 로그인, 학습 기록 동기화와 AI 요청을 처리합니다.

개인 기록은 계정별로 저장됩니다. 공유 기능을 사용하거나 외부 서비스에 직접 자료를 보내면 선택한 대상에게 해당 정보가 전달됩니다.

AI와 음성 처리

AI 학습 요청 시 질문, 학습 문맥과 사용자가 선택한 자료가 선택한 AI 제공자(Google Gemini, OpenAI 또는 Anthropic)에게 전송됩니다. 음성 기능을 켜면 마이크 접근을 요청하며, 브라우저의 음성 인식 기능이 음성을 처리하고 변환된 텍스트가 대화에 사용됩니다. 사용하는 브라우저·음성 서비스가 음성 데이터를 처리할 수 있습니다. 브라우저의 음성 인식을 사용할 수 없으면 선택한 음성 입력을 짧게 녹음해 학습 서버와 Google Gemini에 전달하여 텍스트로 변환합니다. 음성 원본은 학습 기록의 별도 녹음 파일로 저장하지 않으며, 변환된 텍스트는 대화와 학습 기록에 사용됩니다. 제공자의 요청·보관 정책도 적용됩니다. AI 요청에 비밀번호, 주민등록번호 등 불필요한 민감정보를 넣지 마세요. 제공자의 처리 위치·보관 방식은 각 제공자의 정책을 따릅니다.

보관과 삭제

계정과 서비스 기록은 서비스 이용 중 보관하고 계정 삭제 시 함께 삭제하는 것을 원칙으로 합니다. 신고·분쟁 대응 또는 법적 의무로 별도 보관이 필요하면 삭제 요청 처리 시 해당 항목과 보관 사유·기간을 안내합니다. 다른 기기에 남은 다운로드 파일과 로컬 기록은 해당 기기에서 직접 삭제해야 합니다.

이용자의 선택

앱에서 기록을 관리하고 로그아웃할 수 있습니다. 마이크·파일 접근은 해당 기능을 선택할 때만 요청하며 기기나 브라우저 설정에서 철회할 수 있습니다. 계정 삭제는 계정 삭제 안내에서 요청할 수 있습니다. 개인정보 열람·정정과 처리 관련 문의는 운영자 이메일로 보내 주세요.

보호 조치

서비스 통신에는 HTTPS를 사용하고 계정 인증과 접근 규칙으로 개인 데이터 접근을 제한합니다. 개인정보 판매와 광고 타기팅을 위해 수집하지 않습니다.
